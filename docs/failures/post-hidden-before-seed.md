# 발행한 글이 사이트에 안 보임 (2026-11-17)

## 막힌 일
관리자에서 글을 발행했는데 메인과 카테고리에 나오지 않았다. 샘플 글만 보였다.

## 원인
사이트가 Firestore의 설정 문서(`site/config`)가 **있을 때만** DB의 글을 읽고, 없으면 `data.js`의 샘플 데이터로 되돌아가게 만들었다. "샘플 데이터 올리기"를 하기 전에는 설정 문서가 없어서 발행한 글을 무시했다. 또 수정 코드를 GitHub에만 올리고 Firebase 호스팅에 배포하지 않아서, 배포본은 계속 옛 코드였다.

## 푼 방법
`loadCfg()`를 고쳐서 설정 문서가 없어도 발행된 글이 있으면 그 글을 쓰고, 설정·메뉴·메인만 기본값을 쓴다. 호스팅을 재배포했다.

## 다시 안 겪으려면
- 사이트 코드를 고치면 GitHub 푸시와 **Firebase 호스팅 배포는 별개**임을 기억한다. 둘 다 했는지 확인한다.
- 폴백(DB 실패 시 기본 데이터)은 "DB 글을 숨기지 않는 방향"으로 만든다.
- 처음 설정할 때는 관리자 "데이터" 탭의 "샘플 데이터 올리기"를 먼저 한 번 한다.
