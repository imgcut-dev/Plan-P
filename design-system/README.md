# Plan-P

AI와 프로덕트 기획을 기록하는 블로그의 디자인 시스템입니다. 목표는 하나, **글이 먼저 읽히는 화면**입니다. 메인, 글 목록, 글 상세, 관리자 글쓰기 화면이 이 값만 조합해서 만들어집니다.

화면 시안: https://claude.ai/artifact/YUzSDnPEaNq9AvGA9swRL3

## 원칙

1. **포인트는 한 가지 색입니다.** 파랑(`blue-600`)은 주요 버튼, 선택된 칩, 현재 위치, 링크에만 씁니다. 장식에 흩뿌리지 않습니다.
2. **평평한 면과 얇은 선입니다.** 영역은 1px `line` 선이나 옅은 `panel` 면으로 나눕니다. 그림자와 그라데이션은 쓰지 않습니다.
3. **글이 중심입니다.** 광고 영역이 없고, 제목과 본문이 화면의 중심입니다. 본문은 `body-lg`(17px, 줄 간격 1.9)로 오래 읽어도 편하게 합니다.

## 말투

- 한국어 존댓말, 짧은 문장을 씁니다. 어려운 말은 쉬운 말로 풀어 씁니다.
- 버튼은 무엇이 일어나는지 동사로 씁니다. "발행", "임시저장", "이 글 삭제".
- 상태 메시지는 한 줄입니다. "발행했습니다", "임시저장했습니다".
- 오류는 무엇이 잘못됐고 어떻게 고치는지 알려 줍니다. 사과 문구나 모호한 표현은 쓰지 않습니다. 예: "제목을 입력하세요".
- 날짜는 "2026년 11월 12일" 형식입니다.

## 시각 기준

### 색
- 글자는 `ink`, 보조 글자는 `muted`, 선은 `line`, 바탕은 `surface` 또는 `surface-alt`입니다.
- 흰 바탕 위 파랑 글자는 `brand-text`(`blue-700`, 7.9:1)입니다. `blue-500`은 글자색으로 쓰지 않습니다(4.47:1).
- 파랑 면(`brand`) 위 글자는 흰색입니다(6.29:1).
- 정보를 묶는 영역은 `panel`입니다. 테두리 없이 면만 씁니다. 패널 안 목록 항목 사이의 선은 `panel-line`입니다. 패널 안의 입력창은 `surface`(흰색)입니다.
- `success`, `warning`, `danger`는 상태에만 씁니다. 상태는 색만으로 전하지 않고 글자를 함께 씁니다.

### 글자
- 글꼴은 Noto Sans KR 하나입니다. 굵기는 400, 500, 700만 씁니다.
- 제목은 `display`(36), `h1`(30), `h2`(24), `h3`(20), 본문은 `body-lg`(17), `body`(15), `small`(13), `caption`(12)입니다.

### 간격과 모서리
- 간격은 4px 단위 8단계(`space-1`~`space-8`)만 씁니다.
- 모서리는 라벨 `radius-xs`(6), 버튼·패널 `radius-sm`(8), 입력창 `radius-md`(10), 큰 카드 `radius-lg`(14), 필터 칩 `radius-pill`입니다.

### 레이아웃
- 콘텐츠 폭은 최대 1160px, 좌우 여백 24px(`space-5`)입니다. 좁은 화면에서도 16px(`space-4`) 이상 둡니다.
- 글 그리드는 3열이고 900px 이하에서 1~2열로 줄입니다.
- 글 상세는 본문 최대 760px + 사이드바 320px, 사이 간격 `space-7`입니다.
- 관리자는 왼쪽 메뉴 232px + 본문 + 오른쪽 설정 패널 320px입니다.
- 헤더 높이는 64px이고 현재 메뉴 아래에 3px `brand` 선을 긋습니다.

## 쓰는 법

**이렇게 합니다**
- 한 화면에 주요 버튼(`brand` 면)은 하나만 둡니다.
- 정보 묶음은 패널, 입력창은 `line` 테두리 1px로 구분합니다.
- 아이콘만 있는 버튼에는 `aria-label`을 붙입니다.
- 입력창에 포커스가 오면 테두리를 `brand`로 바꿉니다.

**하지 않습니다**
- 그림자, 그라데이션, 이모지로 강조하지 않습니다.
- 광고 영역이나 광고처럼 보이는 배너를 넣지 않습니다.
- 같은 화면에서 파랑 외의 포인트 색을 추가하지 않습니다.
- 목록과 카드의 모서리에 정해진 값 외의 값을 쓰지 않습니다.

## 로고

로고는 `brand` 면의 둥근 사각형(`radius-sm`) 안에 흰색 "P"를 넣은 마크와 "PLAN-P" 글자를 나란히 놓은 형태입니다. 별도 이미지 파일은 없고 글자로 만듭니다.
