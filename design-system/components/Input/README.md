# Input

글자를 입력하는 칸입니다. 모든 입력창에는 눈에 보이는 `<label>`을 연결합니다.

- 높이 44px(관리자 안에서는 40px), 모서리 `radius-md`, 테두리 `line` 1px, 면 `surface`.
- 포커스: 테두리를 `blue-600`으로 바꿉니다. 외곽선(outline)은 켜지 않고 테두리 색으로 표시합니다.
- 오류: 테두리와 안내 문구를 `danger`로 하고, 무엇을 고쳐야 하는지 한 줄로 씁니다. 예: "제목을 입력하세요."
- 안내 문구와 placeholder는 `muted`보다 진하게 쓰지 않습니다.
