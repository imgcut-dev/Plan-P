# PostCard

최신 글 그리드에 쓰는 글 카드입니다. 썸네일, 날짜, 제목, 요약, 태그 순으로 쌓습니다.

- 썸네일 비율 16:10, 모서리 12px, 썸네일 왼쪽 아래에 흰 라벨을 올립니다. 이미지가 없으면 `blue-100` 면을 씁니다.
- 날짜 `caption`/`muted`, 제목 `h3` 계열 17px 700, 요약 `body` 14px/`muted`(두 줄까지).
- 태그 글자는 `blue-700` 12px 500입니다.
- 카드에는 테두리와 그림자를 쓰지 않습니다. 호버하면 제목 색만 `blue-700`으로 바꿉니다.
- 카드 사이 간격은 가로 20px, 세로 28px, 3열 그리드입니다.
