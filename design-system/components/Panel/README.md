# Panel

정보 묶음을 테두리 없이 연한 파랑 면으로 감싸는 영역입니다. 소개 카드, 카테고리 목록, 이전·다음 글, 관리자 설정에 씁니다.

- 면 `panel`(#E8F0FE), 모서리 `radius-sm`, 테두리와 그림자 없음.
- 안쪽 여백 18~24px(`space-4`~`space-5`).
- 목록 항목 사이의 선은 `panel-line`입니다.
- 패널 안의 입력창은 `surface`(흰색) 면에 `line` 테두리를 씁니다.
- 패널 위의 글자는 `ink`와 `muted`를 쓰고 대비를 유지합니다.
- 패널 안에 패널을 넣지 않습니다.
