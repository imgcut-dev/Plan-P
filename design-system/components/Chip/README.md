- **필터 칩**: 목록 위에서 카테고리를 고릅니다. 높이 34px, 모서리 `radius-pill`. 선택된 칩은 `blue-600` 면에 흰 글자, 나머지는 `line` 테두리.
- **라벨**: 글의 분류를 보여 줍니다. 높이 22px, 모서리 `radius-xs`, 면 `blue-50`, 글자 `blue-700` 700. 썸네일 위에서는 흰 면을 씁니다.
- **태그**: 본문 하단에 둡니다. 높이 32px, 면 `surface-alt`, 글자 `blue-700`, 앞에 `#`을 붙입니다.
