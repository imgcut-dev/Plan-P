# Button

동작을 실행하는 버튼입니다. 한 화면에 주요 버튼(`blue-600` 면, 흰 글자)은 하나만 둡니다.

- **주요**: 발행, 로그인처럼 화면의 핵심 동작. 면 `blue-600`, 눌렀을 때 `blue-800`.
- **보조**: 테두리 `blue-600`, 글자 `blue-700`. 주요 동작 옆의 대안.
- **기본**: 테두리 `line`, 글자 `ink`. 임시저장, 수정, 취소.
- **비활성**: 면 `line`, 글자 `muted`.
- 높이 42px(작게 36px), 모서리 `radius-sm`, 글자 `small` 700.
- 삭제처럼 되돌리기 어려운 동작은 글자색 `danger`에 `line` 테두리로 쓰고 주요 버튼으로 만들지 않습니다.
